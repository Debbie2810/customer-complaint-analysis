
# 📊 Customer Complaint Analysis Dashboard

This is a complete Business Analyst project using public complaint data from the Consumer Financial Protection Bureau (CFPB). The objective is to identify complaint trends, service gaps, and company performance issues to improve customer satisfaction.

---

## 🔍 Project Objectives
- Identify top complaint categories
- Analyze complaint volumes by state and company
- Measure response timeliness
- Summarize key insights and business recommendations

---

## 📁 Project Files
| File | Description |
|------|-------------|
| `BRD.pdf` | Business Requirements Document |
| `Insight_Summary.pdf` | Final summary with actionable insights |
| `complaint_analysis.ipynb` | Code notebook (Python, Pandas, Matplotlib, Seaborn) |
| `complaints_sample.csv` | Sample data (~50K rows for performance) |
